# Data Center Operations 360 — Episode Companions

These are **public, learner-facing companion documents** for completed hands-on project parts.

After each part of the [Build Guide](../Build-Guide.md) has been completed and checked, two separate Markdown companions will be added:

- **Twinkle & Celestyn — Design & Troubleshooting Lab:** Twinkle walks through the exact maker-portal navigation, configurations, formulas and workflow construction. Celestyn explains expected results, verification, errors, troubleshooting and fixes. Each companion links to its Build Guide section and practice dataset.
- **Arka & Veda — Enterprise Architecture & Innovation Lab:** Arka explains architecture, data modeling, application boundaries and technology choices. Veda examines governance, security, reliability, business tradeoffs and opportunities for improvement, using the completed project as evidence.

The two documents for a part will be published **only after that part is finalized**. They are educational reading companions, not private production scripts or unpublished planning records.

**Privacy:** This is a public GitHub repository. Do not commit confidential scripts, unpublished production instructions, private prompts, actual organization credentials, real tenant IDs or sensitive operational information. Deleting a file later does not necessarily erase it from Git history.
